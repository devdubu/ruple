# 공통 개발 기반 현황과 다음 작업

2026-10-30 기준입니다. 트랙 A·B가 각자 격리된 환경에서 모듈 설계에 집중하도록 공통 실행·검증·협업 기반을 제공합니다. 이번 변경은 문서 정리이며 애플리케이션 코드·공개 계약·서버 설정을 변경하지 않습니다.

## 확정한 방향

- 두 트랙은 독립 환경에서 개발하고 공개 계약으로 연결하는 소규모 MSA를 기준으로 합니다. 다른 서비스의 소스·DB를 직접 참조하지 않습니다.
- 트랙 A는 M1 상황 수집·M2 상황 해석과 AI/RAG 연계를, 트랙 B는 M3 루틴 관리·M4 실행 판단·M5 오케스트레이션·M6 상호작용과 웹·차량 셸을 담당합니다. 담당 실명은 🚧 미배정입니다.
- 기초팀은 공통 규약·템플릿·검증·실행 환경을 제공합니다. 출퇴근 흐름의 세부 필드·조건·승인·만료·취소 정책은 기능 담당자가 설계하고 공동 검토합니다.
- 공통 UI는 Pleos의 공식 색상·타이포·상태 기준을 참고합니다. 웹에서의 의미 매핑과 크기 조정은 Ruple 기준으로 문서화하며 실제 차량 호스트 적합성은 별도 검증합니다.
- 코드는 GitHub에서 관리하고 내부 GitLab과 기존 N100 Runner를 CI/CD에 사용하는 방향입니다. 지금은 GitLab 접속 없이 저장소 내 컨테이너 기반부터 준비합니다.
