# 차량 호스트 경계

트랙 B의 Android 호스트·Pleos 네이티브 브리지 위치입니다. 아직 Capacitor·WebView 호환 시험 전이므로 빌드·실행 대상은 만들지 않습니다.

기존 [Pleos SDK 검증 앱](../../prototypes/pleos-nav-probe/README.md)은 독립적으로 유지합니다. 공유 웹을 차량에서 실행할 수 있는지 먼저 확인하고, SDK 초기화·조회·경로 요청·콜백·화면 전환·일시 중단/재개를 시험합니다.

차량 구현은 다른 서비스 소스나 DB를 참조하지 않습니다. 공개 명령·보고 계약으로 연결하며, 상세 필드와 사용자 재확인 정책은 미정입니다.
